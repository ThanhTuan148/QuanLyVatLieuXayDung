## 🚀 Khởi Động

### 1. Install Dependencies
```bash
cd Frontend
npm install
```

### 2. Start Frontend
```bash
npm start
```

### 3. Login
```
URL: http://localhost:3001/login
Email: admin@example.com
Password: password123
```

### 4. View Dashboard
```
http://localhost:3001/dashboard
```
